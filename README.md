# Commercial Valuation & Pricing Model

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://<your-app-name>.streamlit.app)

An automated capital budgeting and commercial valuation engine for facility management tenders. Computes Net Present Value (NPV), Internal Rate of Return (IRR), Net Working Capital (NWC) drag, and parametric benchmark validation against Class 5 CER cost models.

### Live Demo & Usage
1. Open the [Live Web Application](https://<your-app-name>.streamlit.app).
2. Download `Pricing_Inputs_Template.xlsx`.
3. Adjust operational shifts, headcount, and discount rates.
4. Upload the modified file to generate dynamic valuation metrics and download the compiled `Commercial_Valuation_Results.xlsx`.
